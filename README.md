# Date Invitation 💌

A cute interactive website for inviting someone on a date.

## Features

- Multi-step date invitation flow
- Playful “No” button that moves away
- Date and time selection
- Food preference selection
- Personalized final confirmation message
- Animated hearts and GIFs
- Responsive design for mobile and desktop

## Built With

- HTML
- CSS
- JavaScript

## How to Use

1. Open the website.
2. Click **Yes**.
3. Choose a date and time.
4. Pick what you want to eat.
5. Enjoy your date plan!
